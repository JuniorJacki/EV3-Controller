A powerful C# WPF application designed to interface directly with a **LEGO Mindstorms EV3 Hub**, allowing real-time telemetry and advanced hardware control.

> ⚠️ **Project Status:** This project is complete and no longer actively updated, but remains fully functional as an open-source reference.

---

### ✨ Features

* **📊 Live Telemetry:** Read and monitor incoming sensor data from the EV3 Hub dynamically.
* **🕹️ Flexible Motor Control:** Command and steer motors using multiple variable input methods:
  * **WiiMote Integration:** Use a Nintendo Wii Remote for motion-based or tactile hardware control.
  * **Custom Keybindings:** Standard keyboard layout controls for precise testing.

---

### 🔌 Third-Party APIs Used

This project leverages the following libraries to communicate with the hardware:
* 📦 **[Legoev3](https://github.com/BrianPeek/legoev3)** – Core API wrapper for EV3 Hub communication.
* 📦 **[WiimoteLib](https://github.com/BrianPeek/WiimoteLib)** – Managed library for interfacing with Nintendo Wii Remotes.
